About this site

I'm a university student in Japan. I'm not a professional developer — I never studied computer science — but over the past while I've been using AI coding assistants (mainly Claude Code) to actually build working software, not just talk about it.

So far that's included things like (each link opens the actual working tool):

  • A cost calculator that turns ingredient/material prices into a per-product cost and profit margin
  • A batch image/PDF processing tool
  • A small product-catalog site and matching admin tool built for a local shop's use case ("Yui" / "fushi")

None of these have made me rich. I'm writing this in August 2026, before this site has any real traffic, any affiliate income, or any audience. I'd rather say that plainly than pretend otherwise.

What I'm trying to do here

Two things, honestly:

  1. Keep a real record — in English, my second language — of what I actually build, what breaks, and how long things really take when a beginner uses AI tools instead of writing everything by hand.
  2. If that record is useful to other people trying the same thing, and if a product or tool I genuinely use happens to have an affiliate program, I may link to it. Any such link will always be disclosed — see the disclosure page. I won't recommend something I haven't actually used, with one labeled exception: the gear guide, which is openly research-based rather than a personal-use list, because I don't own most of this gear myself yet.

I'm keeping my name and university off this page for now. If that changes, this page will change with it.
